# WXCOMMAND-PRO Brand Guide

**Project name:** WXCOMMAND-PRO  
**Descriptor:** Weather Intelligence & Mesh Radio Command Center  
**Tagline:** Weather Intelligence. Mesh Communications. One Command Center.

## Voice and positioning
- Professional, clear, calm, and technically accurate.
- Prioritize situational awareness, operator control, and reliable workflows.
- Avoid claims of guaranteed delivery, official agency affiliation, or emergency certification.
- Refer to Meshtastic and MeshCore as supported external radio ecosystems, not proprietary WXCOMMAND-PRO technology.

## Visual identity
- Background: `#101a22`
- Panels: `#1b2a35`
- Teal accent: `#67c6be`
- Primary text: `#e6eff2`
- Secondary text: `#a2b6c0`
- Warnings: `#f9c16a`
- Use accessible contrast and visible keyboard focus states.

## GitHub repository settings (manual update required)
**Recommended repository name:** `WXCOMMAND-PRO`

**Description (paste into GitHub About):**
Self-hosted weather intelligence and mesh radio command center for Meshtastic and MeshCore. NWS alerts, radio monitoring, and controlled broadcasts.

**Suggested topics:**
`weather-alerts`, `meshtastic`, `meshcore`, `lora`, `raspberry-pi`, `nws`, `emergency-communications`, `self-hosted`, `python`, `fastapi`

**Website:** Leave blank until there is a project-owned landing page.

**GitHub Settings → General → Repository name:** Change from `MeshWX1` to `WXCOMMAND-PRO`.

After the rename, update remote URLs in local clones and all CI, install,
documentation, Docker image, and update-check references. GitHub redirects
help with old links but are not a substitute for updating dependencies.

## Release policy
Do not merge development branches or publish a new version until the
release checklist passes. Branding changes alone do not validate software.
